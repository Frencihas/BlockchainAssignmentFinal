# Blockchain Assignment

A C# blockchain simulation developed in Visual Studio.

## Features
- Blockchain with linked blocks
- SHA256 hashing
- Proof-of-work mining
- Dynamic mining difficulty
- Wallet generation
- Signed transactions
- Transaction validation
- Mining rewards
- Balance calculation
- Blockchain tampering detection

## Technologies
- C#
- Windows Forms
- .NET Framework
- Visual Studio
