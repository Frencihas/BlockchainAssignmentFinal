# Blockchain Assignment

A C# blockchain simulation developed in Visual Studio.

## Features

- Blockchain with linked blocks
- SHA-256 hashing
- Proof-of-work mining
- Dynamic mining difficulty
- Wallet generation
- Signed transactions
- Transaction validation
- Mining rewards
- Balance calculation
- Blockchain tampering detection
- Transaction fee selection using greedy prioritisation

## Technologies

- C#
- Windows Forms
- .NET Framework
- Visual Studio

## How to Run

1. Download or clone the repository.
2. Open BlockchainAssignment.sln in Visual Studio.
3. Build the solution.
4. Run the Windows Forms application.
5. Use the application output to test blockchain creation, mining, transactions, validation and tampering detection.

## Project Structure

- Block.cs – block creation, hashing and proof-of-work mining
- Blockchain.cs – blockchain storage, validation and transaction selection
- Transaction.cs – transaction data, fees and validation
- Wallet.cs – wallet generation and key handling
- HashTools.cs – SHA-256 hashing utilities
- BlockchainApp.cs – Windows Forms interface and testing output
